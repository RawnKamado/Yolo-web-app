# Contributing

Thank you for your interest in the YOLO Web Application.

This is a personal project developed and maintained by **Duong Quang Bao Quoc**. The project is primarily developed independently for learning, experimentation, and demonstrating a complete YOLO-based web application.

## Development

If you would like to explore or modify the project, you can clone the repository:

```bash
git clone https://github.com/RawnKamado/Yolo-web-app.git
cd Yolo-web-app
```

### Backend

```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload --port 8000
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

## Suggestions and Feedback

Suggestions, bug reports, and improvement ideas are welcome.

When reporting an issue, please provide:

- A clear description of the problem
- Steps to reproduce the issue
- Expected behavior
- Actual behavior
- Relevant error messages or logs

## Pull Requests

Contributions and pull requests may be considered depending on the scope and direction of the project.

For larger changes, please open an issue first to discuss the proposed change.

## Code Quality

Please keep changes:

- Clear and readable
- Consistent with the existing project structure
- Focused on the intended purpose
- Tested before submission

Thank you for your interest in the project!
